# Tarea No.11 Repositorio de Gastos Con Update y Delete

## Descripción

Programa desarrollado en C# que utiliza:

- Cadena de conexion a Base de datos
- SELECT FROM WHERE
- DELETE FROM WHERE
- UPDATE FROM WHERE
- Creacion de GastosDB en (localdb)\MSSQLLocalDB
- using
- SqlConnection
- SqlCommand
- SqlDataReader
- .ExecuteReader()
- .Read
- .Parameters.AddWithValue
- @Valor
- .GetInt32()
- .GetString()
- .GetDecimal()
- Interpolacion
- Ternario
- if
- Try/Catch
